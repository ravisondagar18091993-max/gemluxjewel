HOW TO UNGROUP STONE SHAPE VALUES (Gemlux Jewels)
=================================================

WHAT "GROUPED" MEANS ON YOUR STORE
----------------------------------

Right now your Search & Discovery "Stone shape" filter shows 8 options:

  Heart, Marquise, Other, Oval, Pear, Rectangular, Round, Square

These come from Shopify's STANDARD PRODUCT TAXONOMY (category metafield).
They are "parent" or base shapes — not your full list.

Your metaobjects list has 13 detailed entries, for example:

  Cushion Cut, Moval Cut, Marquise Cut, Princess Cut, Asscher cut,
  Square, Heart, Pear, Baguette, Marquise, Round, Oval, Emerald Cut

Each metaobject has:
  - Label          (display name, e.g. "Cushion Cut")
  - Base stone shape (taxonomy group, e.g. "Other", "Oval", "Square")

So "Cushion Cut" and "Baguette" both sit under base shape "Other".
The filter groups them — customers only see "Other", not each cut name.

That is why the homepage can show 13 shapes (from metaobjects) but the
filter dropdown only shows 8 (from taxonomy).


CAN YOU "UNGROUP" THE 8 TAXONOMY VALUES?
-----------------------------------------

No — not within the same Stone shape category filter.

Shopify Search & Discovery does not let you split "Other" into Cushion,
Baguette, Radiant, etc. when those are all one taxonomy bucket.

To show EACH cut as its own filter option, you need a SEPARATE data source
(a custom metafield or metaobject reference on products), not the
built-in category "Stone shape" field alone.


OPTION A — USE A CUSTOM METAFIELD FOR DETAILED SHAPES (RECOMMENDED)
-------------------------------------------------------------------

This is the usual way to "ungroup" and filter by exact cut name.

STEP 1 — Create a product metafield definition
  1. Shopify Admin → Settings → Custom data → Products
  2. Add definition, for example:
       Name:     Detailed stone shape
       Namespace and key: custom.detailed_stone_shape
       Type:     Single line text  OR  Metaobject reference
                 (if metaobject reference, link to shopify--stone-shape)
  3. Save

STEP 2 — Assign the value on each product
  For every product, set the detailed shape, e.g.:
    - Cushion Cut
    - Princess Cut
    - Emerald Cut
  Must match your metaobject Label text exactly if you use references.

  Bulk options:
    - CSV product import (column for metafield)
    - Shopify bulk editor
    - Apps for bulk metafield edit

STEP 3 — Add a NEW filter in Search & Discovery (do not replace Stone shape)
  1. Apps → Search & Discovery → Filters
  2. Add filter → choose your new metafield
     "Detailed stone shape" (or metaobject reference field)
  3. Save

STEP 4 — Theme (already partly set up)
  - Homepage "Shop by Stone Shape" can load from metaobjects
  - Collection filter icons: add Shape icon blocks whose names match
    the NEW filter values exactly (e.g. "Cushion Cut", not "Other")

RESULT:
  - Old filter: Stone shape → 8 grouped taxonomy values (optional, keep or hide)
  - New filter: Detailed stone shape → 13 individual values (ungrouped)


OPTION B — USE METAOBJECTS ONLY (NO EXTRA METAFIELD ON PRODUCTS)
--------------------------------------------------------------

Metaobjects alone do NOT power Search & Discovery filters unless products
reference them.

To filter by metaobject entry you must either:
  1. Add a product metafield of type "Metaobject reference" pointing to
     shopify--stone-shape, and assign one entry per product, OR
  2. Use metaobjects only for display (homepage slider, menus) and keep
     taxonomy filter for actual product filtering.

Enable storefront access (required for theme):
  Settings → Metafields and metaobjects → Stone shape
  → Metaobject options → turn ON "Storefront API access"


OPTION C — KEEP GROUPED FILTER, USE SLIDER FOR ALL 13 SHAPES
------------------------------------------------------------

If you do not need 13 items inside the filter dropdown:

  - Filter: keep Search & Discovery "Stone shape" (8 values) for filtering
  - Homepage slider: load all 13 from metaobjects (theme setting ON)
  - Link each slider item to collection + base shape filter param
    (e.g. click "Cushion Cut" → collection filtered by Other or Square)

This is not true "ungrouping" but works without re-tagging all products.


SEARCH & DISCOVERY — FILTER SETTINGS CHECKLIST
----------------------------------------------

1. Apps → Search & Discovery → Filters
2. Confirm "Stone shape" is the CATEGORY metafield (8 values) — grouped
3. To ungroup: add a second filter on custom.detailed_stone_shape or
   metaobject reference field (13 values)
4. Filters → edit → you can rename label shown to customers
5. Save and wait a few minutes for storefront to refresh


PRODUCT CATEGORY VS CUSTOM FIELD (IMPORTANT)
--------------------------------------------

| Source                         | Filter shows      | Ungrouped? |
|--------------------------------|-------------------|------------|
| Category: Stone shape          | 8 base shapes     | No         |
| Custom metafield (text/list)   | Your exact labels | Yes        |
| Metaobject reference on product| Each metaobject   | Yes        |

Products must have the correct field filled or they will not appear when
that filter value is selected.


MATCHING NAMES (AVOID BLANK ICONS IN FILTER)
--------------------------------------------

Theme Shape icon blocks must use the EXACT same spelling as the filter value:

  Filter value in Search & Discovery    Block title in theme
  ------------------------------------    ----------------------
  Cushion Cut                             Cushion Cut
  Rectangular                             Rectangular
  Other                                   Other

Case usually does not matter; spelling must match.


CSV / BULK IMPORT EXAMPLE (custom text metafield)
-------------------------------------------------

If metafield is custom.detailed_stone_shape (single line text), in product
CSV add a column (header depends on Shopify export format), e.g.:

  Metafield: custom.detailed_stone_shape [single_line_text_field]

Row example:
  ...,Cushion Cut,...

Re-import products, then add the metafield as a filter in Search & Discovery.


QUICK DECISION GUIDE
--------------------

Want 13 separate filter checkboxes?
  → Option A: custom metafield or metaobject reference on products + new filter

OK with 8 filters but 13 shapes on homepage only?
  → Option C: keep current setup

Want products in Shopify admin to pick from your 13 metaobject list?
  → Product metafield type: Metaobject reference → shopify--stone-shape
  → Assign per product → add that metafield as filter in Search & Discovery

SUMMARY IN ONE SENTENCE
-----------------------

You cannot ungroup "Other" or "Rectangular" inside the default Stone shape
category filter; create a custom product metafield (or metaobject reference),
fill it on every product, and add that field as a new filter in Search &
Discovery to show all 13 cut names separately.
